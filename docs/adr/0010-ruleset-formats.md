# ADR 0010. Поддерживаемые форматы списков и совместимость версий

**Статус:** принято · **Дата:** 2026-08-26

## Контекст

Списки доменов приходят из разных экосистем: plain-списки, формат v2ray/sing-box
с префиксами, hosts-файлы, adblock-подобные файлы с комментариями.

## Решение

Один нормализатор (`shared/domainset`) для всех источников:

| Вход | Результат |
|---|---|
| `example.com` | exact |
| `full:example.com`, `domain-full:` | exact |
| `domain:example.com` | suffix (семантика v2ray: домен и поддомены) |
| `domain-suffix:`, `suffix:` | suffix |
| `*.example.com`, `.example.com`, `+.example.com` | suffix, apex включён |
| `0.0.0.0 example.com` | exact (hosts-файл) |
| `domain-keyword:` | отклоняется с предупреждением |
| `regexp:` / `domain-regex:` | только при явном включении regex |

Нормализация: снятие BOM и комментариев, IDNA в ASCII, приведение к нижнему
регистру, снятие одной завершающей точки, проверка длин меток и общей длины,
дедупликация, детерминированная сортировка, SHA-256 содержимого.

Сопоставление суффикса — строго по границе метки.

## Альтернативы

- **Поддержать `domain-keyword`.** Подстрочное совпадение непредсказуемо
  захватывает чужие домены. Отклоняется явно, а не молча игнорируется.
- **Разрешить regex по умолчанию.** Риск ReDoS и непрозрачных правил. Включается
  осознанно; движок RE2 даёт линейное время, длина ограничена 256 символами.

## Последствия

- Один и тот же нормализованный набор используется для подмены DNS,
  маршрутизации ingress и allowlist egress — рассинхрон невозможен по конструкции.
- Совместимость версий артефакта — поле `schema_version`; агент отказывается
  применять незнакомую схему.
- Пересечение доменов между сервисами с одинаковым приоритетом останавливает
  сборку со списком конфликтов, а не выбирает победителя случайно.

## Тест

`shared/domainset` — нормализация IDNA, границы суффиксов, каждый формат,
BOM и комментарии, детерминированность хеша, слияние с исключениями.
`TestEqualPriorityConflictFailsCompilation` — конфликт останавливает сборку.
