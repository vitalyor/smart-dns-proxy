# Каталог доменов сервисов

Курируемые списки доменов для разблокировки конкретных сервисов. Панель
подтягивает их как источник (Автообновление доменов в окне сервиса) по raw-ссылке
и пересобирает конфигурацию.

## Файлы

| Файл | Сервис |
|------|--------|
| [`openai.lst`](openai.lst) | OpenAI — ChatGPT, Codex, Sora, API |
| [`anthropic.lst`](anthropic.lst) | Anthropic — Claude (веб, API, Console) |
| [`google-ai.lst`](google-ai.lst) | Google AI — Gemini, AI Studio, NotebookLM, Jules, Labs |
| [`xai.lst`](xai.lst) | xAI — Grok + X (Twitter) |

## Как подключить в панели

В окне сервиса → «Автообновление доменов» → «Добавить источник» → тип
«GitHub: прямая ссылка», адрес:

```
https://raw.githubusercontent.com/vitalyor/smart-dns-proxy/main/catalog/openai.lst
```

(Ссылки живут на ветке `main` — начинают работать после мержа.)

## Формат

Один домен в строке. **Голая строка = домен и все его поддомены** (суффиксное
совпадение): `openai.com` покрывает и `api.openai.com`, и `chat.openai.com`.

- `full:host` — только точный хост, без поддоменов.
- `#` в начале строки или после домена — комментарий.
- Пустые строки игнорируются.

Осторожно с широкими зонами: не пишите голыми `google.com`/`googleapis.com` —
это уведёт в egress вообще весь Google. Для сервисных бэкендов указывайте
конкретные хосты (`jnn-pa.googleapis.com`), они как суффикс матчат только свой
поддомен.

## Источники

Домены собраны из официальных allowlist-документов вендоров (фаервол/сеть) и
перепроверены; ссылки указаны в шапке каждого `.lst`. При изменениях у вендора
правьте файл здесь — у всех подтянется автоматически.
