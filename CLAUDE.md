# Правила работы с этим репозиторием

Репозиторий публичный. Всё, что сюда попадает, видно всем и остаётся в истории
навсегда — даже если файл удалить следующим коммитом.

## Перед первым коммитом на новой машине

```sh
git config core.hooksPath .githooks
```

Хуки не переносятся вместе с клоном — это настройка каждой копии репозитория.
Без неё сторож молчит. Проверить, что включён: `git config core.hooksPath`.

## Что проверять в каждом коммите

Сторож [scripts/check-secrets.sh](scripts/check-secrets.sh) ловит ключи, токены,
пароли со значением, личную почту и боевые IP в том, что уходит в коммит. Он не
всесилен, поэтому глазами — тоже:

- **Смотреть, что именно уходит.** `git status` перед каждым коммитом. Никаких
  `git add .` и `git add -A`: перечислять файлы поимённо. Однажды так уехал
  рабочий документ с адресами всего флота.
- **Адреса и имена хостов** — только `example.net`, `example.org`, `192.0.2.x`,
  `203.0.113.x`. Боевые живут в `.blackbox/` (в игноре) и в панели, не в коде.
- **Имена людей** — в примерах и подсказках интерфейса нейтральные.
- **Никогда**: бандл ноды (base64 с TLS-личностью), содержимое `panel_secrets`,
  токены устройств, дампы базы, `.env`. Всё это выглядит как безобидная строка —
  и именно так утекает: в issue, в пример конфига, в скриншот.

## Чему научил август

Два случая, оба стоили переписывания истории.

**`.gitignore` не действует на уже отслеживаемые файлы.** Правило можно написать
правильно, и оно не сработает, если файл попал в индекс раньше. Лечится
`git rm --cached <файл>` — файл остаётся на диске, но перестаёт ездить.

**Файл без перевода строки в конце.** Дописывание строки в `.gitignore` слепило
её с предыдущей в одно бессмысленное правило и разом отключило обе защиты. Git
об этом не сообщает: неверного синтаксиса в `.gitignore` не бывает, плохой
шаблон просто ничего не находит. Проверять: `tail -c 1 .gitignore | xxd`.

## Разовая ревизия всего дерева

```sh
scripts/check-secrets.sh --all      # всё дерево
scripts/check-secrets.sh --self-test # не разучился ли сторож ловить
```
